# Changelog

## 0.1.0 (unreleased)

- `ArgusNxTensorAnalyses.TensorShapes`: Nx calls whose operand shapes Nx
  rejects (`tensor_shape_mismatch`), and calls Nx accepts where the code
  does not line its axes up (`tensor_axis_misalignment`), modeling Nx 1.0.
- `mix argus_nx_tensor_analyses`: `mix argus` with these analyses beside
  Argus's own.
